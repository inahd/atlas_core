# Plant Entity Model

A plant is a multi-domain field node, and φ measures the relationship between human and plant.

## Core definition
Each plant exists in the field with coordinates:
- θ → time / season / nakshatra relationships
- φ → qualities / element / guna / structure
- ψ → human relationship (approach, proximity, use)

## Multi-domain presence
Each domain speaks independently with attestation. Never derived from another domain:
- ASTROLOGY · AYURVEDA · ETHNOBOTANY · PERMACULTURE · VĀSTU · OTHER TRADITIONS

## φ axis — relationship mode
- witness (observation, respect)
- participant (use, cultivation)  
- extraction (resource use)

Not moralized. Measured as coherence with the field.

## Cultural tradition map
Multiple valid interpretations coexist. Clearly labeled. Never merged prematurely.

## Biopiracy / observed registry
Labeled OBSERVED. Never mixed into traditional domains. Never moralized in core field logic.

## FieldState integration
FieldState does NOT contain plant data.
FieldState may include plants as coherence peaks.
Apps resolve: which plants matter now.

## Design intent
The system reveals what is happening and how the relationship aligns or not.
It does not tell the user what to do.
