# schema_notes.md

**Node types:** TITHI, DEVI, ICON_TOKEN, SOURCE_WITNESS, SCOPE  
**Edges:** DEVI–[has_attribute]->ICON_TOKEN, DEVI–[observed_in]->SOURCE_WITNESS, DEVI–[is_in_scope]->SCOPE, etc.  
**Properties:** authority_source (e.g. _Tantra_, _Prayoga_), default sampradāya/region (if given), stability_layer = experimental, viz_permission = relation_only.  
**Observations vs Interpretation:** icon attributes (OBSERVED) are marked with SOURCE citations; SYSTEM interpretation (capability map) is separate.  
**Promotion Gates:** Node types and edges require community review, relation only until published. Concept events (e.g. propagate to Vishnu Memory) on promote.  
**Quality:** All attributes are directly cited; contradictions are preserved in scope. Variants listed, not flattened. Observed vs interp. strictly separated.
